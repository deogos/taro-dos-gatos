# Tarô dos Gatos

Um jogo de plataforma 2D em que você controla a gata Neblina. Explore o Jardim da Lua, a Cripta da Força e o Observatório da Estrela, encontre as cartas e use os arcanos para liberar o caminho.

## Como jogar

Na raiz do repositório, inicie um servidor local com Python.

```sh
python -m http.server 8000
```

Abra [localhost:8000](http://localhost:8000) no navegador.

- **Andar** com as setas esquerda e direita ou **A** e **D**.
- **Pular** com **Espaço**, seta para cima ou **W**.
- **Usar a carta** com **E** ou **1** perto do obstáculo.
- **No celular**, use os botões na tela.

Os mapas ficam em `levels.js`.
